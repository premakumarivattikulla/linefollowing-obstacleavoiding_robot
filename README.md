# Line-Following & Obstacle-Avoiding Robot

## Project Overview
This project demonstrates an Arduino-based robot that follows a marked line and detects obstacles in its path. It uses IR sensors for line detection and an ultrasonic sensor to measure the distance to nearby objects.

## Objectives
- Develop a line-following robot.
- Detect obstacles in front of the robot.
- Control DC motors using Arduino.
- Understand sensor interfacing and embedded systems.

## Components Used
- Arduino Uno
- IR line sensors
- HC-SR04 ultrasonic sensor
- DC motors
- Motor driver IC/module
- Breadboard
- Resistors
- Jumper wires
- Power supply

## Working Principle
1. IR sensors detect the line on the surface.
2. The Arduino reads the sensor signals.
3. The ultrasonic sensor measures the distance to obstacles.
4. The Arduino processes the sensor inputs.
5. Motor control signals guide the robot along the line and respond to obstacles.
